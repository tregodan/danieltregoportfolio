Connect the picker to GitHub

One-time setup so the picker can save discs for you. The key stays in this browser only.

  1. Open GitHub → New fine-grained token.
  2. Name it Portfolio picker and pick an expiration (1 year is fine).
  3. Under Repository access, choose Only select repositories → tregodan/danieltrego.
  4. Under Permissions → Repository permissions, set Contents to Read and write.
  5. Click Generate token, copy it, and paste it below.
